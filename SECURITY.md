# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of SEO-IntentRank seriously. If you believe you have found a security vulnerability, please do NOT create a public issue on GitHub.

Instead, please report it directly via:
- **Email**: info@aibuildinfra.com
- **Subject**: `[SECURITY VULNERABILITY] SEO-IntentRank`

Please include detailed steps to reproduce the issue. We will acknowledge receipt within 48 hours and work with you on a swift remediation.
